# 参数系统

参数系统提供**类型化定义、有序覆盖、校验与来源链**。它不是配置面板，不安装包，不执行包内代码，也不改变现有正常配置的默认行为。

## 1. 配置从哪里来

主配置的优先级由低到高：

1. 原有程序默认值；
2. 所选内容包的可选 `params`；
3. 显式参数 JSON / 调用方传入的 `params`；
4. 所选 dotenv 文件；
5. 启动进程环境。

没有指定新文件时不读取任何新参数文件。原有 env 名、旧 allowlist 名、路径派生与空串约定继续有效。dotenv 仍通过 Node 内置加载器读取，进程已有环境值不被文件覆盖。

**模型设置是有意保留的兼容例外**：内建默认 → env（Bot 可以逐字段借 dream）→ 已保存模型设置。环境不能压掉已保存的模型；dream 不反借 Bot。热 reload 坏文件保留整份旧 client，单轮 snapshot 仍固定同一 client。

## 2. 主配置入口

```js
import { loadConfig, CONFIG_PARAM_DEFINITIONS } from '../src/config.js';

const config = loadConfig({ rootDir: projectRoot });
// 非枚举、无值的旁路诊断，不改变原配置 JSON 的结构。
console.log(config.paramSources.QQBOT_MOOD_KAOMOJI_CHANCE);
// { source: 'default', chain: [{ source: 'default' }], sensitive: false }
```

完整目录由 `CONFIG_PARAM_DEFINITIONS` 导出，包括 id、type、default、env、scope、sensitive 与约束。不要把整个配置对象打印到日志：运行配置仍包含调用所需的秘密。只输出 `paramSources`、`paramWarnings` 或经过筛选的目录元数据。

`loadConfig({ rootDir, params, packParams })` 也支持调用方显式提供数据用于装配和合成测试。它们不写回 `process.env`，不触碰持久化模型文件。

### 可选 JSON 文件

在原环境中设置 `QQBOT_PARAMS_FILE`，相对路径按项目根解析。文件是**参数 id → 值的平面 JSON 对象**，例如：

```json
{
  "QQBOT_MOOD_KAOMOJI_CHANCE": 0.25,
  "QQBOT_STYLE_NUDGES": 2,
  "QQBOT_SPOKEN_MAX_CHARS": 60
}
```

只接收已登记的运行参数。部署域（密钥、账号、权限名单、路径等）仍必须通过既有环境入口提供，不能借参数 JSON 或内容包注入。未知键、坏 JSON、非法值会使配置构建失败。

显式调用方 `params` 高于该 JSON，但低层的非法值仍报错，不能靠高层合法值掩盖。所有层都校验，不仅校验最终赢家。

## 3. 内容包参数

格式见 [内容包格式](39-内容包格式.md)。可选 `params` 只允许：

| id | 类型与边界 | 含义 |
| --- | --- | --- |
| `QQBOT_MOOD_TTL_MS` | 正安全整数，毫秒 | 情绪保留时间 |
| `QQBOT_MOOD_KAOMOJI_CHANCE` | 有限数，0–1 | 颜文字倾向 |
| `QQBOT_STYLE_NUDGES` | 非负安全整数 | 风格提示抽取数 |
| `QQBOT_SPOKEN_MAX_CHARS` | 非负安全整数 | 无情绪决策时的分段字数 |
| `QQBOT_SPOKEN_EMOJI_CHANCE` | 有限数，0–1 | 分段表情倾向 |
| `QQBOT_POKE_REPLY_CHANCE` | 有限数，0–1 | 戳一戳回应倾向 |
| `QQBOT_FACE_REPLY_CHANCE` | 有限数，0–1 | 单表情回应倾向 |

包不能设置账号、密钥、权限、预算或路径。未带 `params` 的原包一字不变；无包继续旧回退。按最终 mood theme 选择参数包；多个参数包命中同一主题则拒绝，不能按目录顺序悄悄选一个。

## 4. 纯注册表 API

```js
import { defineParam, resolveParams } from '../src/params.js';

const definitions = [
  defineParam({
    id: 'replyChance', type: 'number', default: 0.5,
    env: 'EXAMPLE_REPLY_CHANCE', min: 0, max: 1, scope: 'runtime',
  }),
];
const result = resolveParams(definitions, {
  contentPack: { replyChance: 0.2 },
  configFile: { replyChance: 0.3 },
  env: { EXAMPLE_REPLY_CHANCE: '0.4' },
});
// result.values.replyChance === 0.4
// result.sources.replyChance.source === 'env'
```

- 支持 boolean、number、int、enum、string、url、path、ms、duration、array、object 和显式 custom parser。
- 布尔接受 `1/true/yes/on` 与 `0/false/no/off`（大小写不敏感）；拼错不是 false。
- number 必须有限；int 是安全整数，不能截断 `12oops` 或 `1.5`；ms 是非负整毫秒。duration 还接受单段 `ms/s/m/h/d`，换算后必须为非负安全整毫秒，不四舍五入。
- url 为绝对 HTTP(S)，不允许嵌入账号密码；它不是 SSRF 授权器。模型 URL 仍复用模型模块更严格的 HTTPS/回环/元数据/query 规则。
- path 不解析/创建路径，只拒绝非字符串与 NUL；相对路径解析仍由消费端按原规则完成。
- enum 使用显式 `values`；parse 在类型校验之前执行，validate 复用已有复杂规则。自定义解析器不是内容包提供的代码。
- `env` 数组用于旧别名兼容，首项最高优先；每个显式别名均校验。空串默认视为未设，`emptyAsUnset:false` 保留有意义空串；不隐式 trim。
- `resolveParamLayers` 支持调用方明确指定层次，用于保留模型的既有设置顺序；不得以此为包绕过部署域限制。

返回 `values`（类型化值）、`inputs`（内部兼容读取的原始显式值）、`sources`（仅元数据）和 `warnings`。**values/inputs 不是脱敏日志接口**；来源链不含值、绝对路径、密文或自定义异常正文。

## 5. 失败与兼容边界

非法输入在连接 QQ、创建真实模型调用和启动服务前拒绝；错误只含固定码、已登记 id 与来源层。显式未知参数报错；未登记的 `QQBOT_` 环境项产生固定警告，普通 PATH 等环境不参与。其他模块已知键有独立目录，不把所有环境变量误判成拼写错误。

本次明确收紧非法整数尾垃圾、错误布尔拼写、非有限值和非法单价静默回退；正常默认、旧 env 和提示词保持。特殊历史语义仍显式保留：`MEITU_PER_GROUP` 仅字面 `0` 关闭、legacy state 空串禁用、普通 raw 空串回默认；sleep/morning/meal 原宽容策略不变。

来源诊断说明的是配置与 client 默认，**不证明**真实模型可用、单次请求覆盖、搜索凭据随模型热更、预算热更新或生产加载版本。积分额度、切日、价目币种和账本规则没有被参数系统重写。

## 6. 测试与实现来源

公开入口 `node scripts/selftest-public.js` 注册纯参数、主配置、模型参数与内容包契约；只用合成数据和临时目录，不需要真实凭据或外部服务。每个新校验包含合法绿/非法红，另用放宽校验变异验证判据确实会失败。

设计规则参考 [Mozilla Convict 6.2.4 文档](https://cdn.jsdelivr.net/npm/convict@6.2.4/README.md)：schema/default/env/sensitive、文件低于环境、有序覆盖和 strict 未知键。由于零依赖约束，仅采用规则；本实现不引入 Convict。相对其宽松 coercion，明确使用严格数值/布尔校验，并验证所有层、单独记录无值来源链；不提供 CLI 参数或第三方格式解析器。
